REPLACING A CARD IN A LINE

What happens today: if a new copy of a stage you already have arrives (say an alt-art Charmeleon for a line that already holds a Charmeleon), the app sends the new one to the front half without asking, "lines tracked once." The only swap it offers is a holo arriving over the same card's normal. To put a nicer card into a line you have to do two separate Moves by hand, and the line shows as incomplete in between.

Proposed: that card gets the pink badge, and its popup shows the line with both cards for that slot side by side. You pick which one stays in the line. The default is "keep the one that's there", so nothing changes unless you choose it. If you swap, you also pick where the card coming out goes, and the whole swap is done in one step, so the line never shows a gap. The holo upgrade uses this same screen, pre-set to swap with the old copy going to bulk, which is today's rule for it.

THREE QUESTIONS FOR YOU

  1. When should the popup open? Proposed: when you tap a card's line badge, and automatically when you reach that card in the checklist ("Done, next card"). The auto-open could feel like a lot on a big haul with many line cards. Want both, or badge-only?
  2. Replace default. Proposed: "keep the one that's there," so a new copy never bumps a card out of a line unless you say so. Or would you rather it default to the newer card when it's a nicer printing (holo, alt art, full art)?
  3. Where a card that comes out of a line goes by default. Proposed: the front half, same colour, which is what happens to an extra copy today. Bulk is one tap away. Would you rather the default be bulk?
